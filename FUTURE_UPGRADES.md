# 🔮 SPARK MSIT — Future Upgrades & Roadmap for Juniors

Welcome to the **SPARK MSIT** contributor community! This document serves as the official product roadmap for junior developers who want to contribute new features, enhancements, and tools to the society portal.

---

> ## 🧠 Crucial Advisory: Use AI Wisely & Protect Codebase Integrity
> 
> **To all junior developers & contributors:**  
> AI coding assistants (ChatGPT, GitHub Copilot, Cursor, Claude, etc.) are powerful tools to accelerate learning and development. However, **AI is an assistant, not a replacement for your engineering judgment.**
>
> 1. **Understand Every Line:** Never copy-paste or commit code generated by AI without thoroughly reading, understanding, and validating what each function and component does.
> 2. **Zero Unverified Commits:** You must test your changes locally across both desktop and mobile viewports.
> 3. **Strict Build Verification:** Always run `npm run build` and `npm run lint` before creating a pull request. A PR with build errors or broken types will not be merged.
> 4. **Preserve Architectural Standards:** Respect existing design tokens (`src/styles/tokens.css`), maintain accessibility standards, and avoid introducing unnecessary external dependencies.
>
> *You are directly responsible for the quality, reliability, and security of every line of code you commit.*

---

## 🏆 Tier 1: Essential & Core Upgrades (High Priority)
*These features are genuinely required for day-to-day society operations, workshop management, and student onboarding.*

### 1. 📝 Interactive Workshop Registration System
**Description:**  
Add a direct registration flow on upcoming event cards in `/events` that opens a clean modal or navigates to a registration form. It can connect with a serverless Next.js API route or Google Forms / Supabase to capture participant details (Name, College Roll Number, Branch, Semester, Email).

### 2. 📜 Certificate Verification Portal (`/verify`)
**Description:**  
A dedicated verification lookup page where students, recruiters, and institutions can enter a unique Certificate ID (issued after attending SPARK workshops and hackathons) to instantly view and verify official digital credentials with cryptographic authenticity badges.

### 3. 📄 Student Research Paper & Project Repository (`/projects`)
**Description:**  
Build an interactive directory showcasing research papers, hardware prototypes, IoT projects, and open-source software built by SPARK members. Include filter tags (*Robotics, AI/ML, IoT, Web3, Aerospace*) and direct links to GitHub repositories, project demos, and IEEE/arXiv paper PDFs.

### 4. 📅 Society Event Calendar & Google Calendar Sync
**Description:**  
Implement a responsive calendar view on the `/events` page showcasing upcoming workshop dates, hackathons, speaker sessions, and project submission deadlines, complete with a one-click "Add to Google Calendar / iCal" export button.

### 5. 📸 Dynamic Event Photo Gallery with Lightbox
**Description:**  
Upgrade the static event galleries in `/events` into an interactive masonry grid with a smooth lightbox zoom modal (using Framer Motion or `yet-another-react-lightbox`) to showcase high-resolution photos and highlights from offline sessions.

## 🚀 Tier 2: High-Value Feature Enhancements (Medium Priority)
*These features significantly elevate user experience, society visibility, and student engagement.*

### 6. 🌓 Smooth Light / Dark Mode Theme Switcher
**Description:**  
Introduce a high-performance theme toggle switch in the floating navbar using Tailwind v4 `dark:` variants and `next-themes`. Ensure all custom tokens (`--spark-bg`, `--spark-ink`, `--spark-surface`) transition smoothly between the dark cosmos theme and a clean light editorial layout.

### 7. 📰 Technical Blog & Editorial Articles (`/blog`)
**Description:**  
Create an MDX-powered technical publishing hub where SPARK members can write deep-dive tutorials, hardware teardowns, AI research summaries, and engineering post-mortems with code syntax highlighting and LaTeX equation formatting.

### 8. 📊 Society Impact & Live Metrics Dashboard (`/stats`)
**Description:**  
An animated analytics section visualizing SPARK's year-over-year impact: number of workshops conducted, students trained, research papers published, hackathon podium finishes, and active multidisciplinary projects.

### 9. 🔍 Global Command Menu (`Ctrl + K` / `Cmd + K` Search)
**Description:**  
Add a modern command palette (using `cmdk`) allowing visitors to press `Ctrl+K` anywhere on the site to quickly search for team members, past workshops, research papers, or jump to specific pages instantly.

### 10. 🪐 3D Orbit Node Click-to-Filter Interaction
**Description:**  
When a user clicks on an orbiting 3D planetary node on the homepage (*Research, Innovation, Collaboration, Workshops, Opportunities*), smoothly animate the camera toward that node and filter the content section below to show projects matching that specific pillar.

### 11. 📧 Automated Newsletter & Workshop Reminders
**Description:**  
Add an email subscription strip in the footer connected to Resend or Mailchimp to send students monthly digests of upcoming technical workshops and research opportunities.

## 💡 Tier 3: Advanced Innovations & Automation (Optional / Future Exploration)
*Cutting-edge integrations and automated workflows for advanced contributors.*

### 12. 💬 Automated Discord / WhatsApp Community Broadcast Bot
**Description:**  
Create a Next.js webhook API route that automatically broadcasts newly announced events and workshops directly to official SPARK Discord channels and WhatsApp announcement groups upon publishing.

### 13. 🛡️ Internal Member Portal & Lab Component Inventory
**Description:**  
A member-only dashboard where inducted SPARK students can log in with their college email to access internal research resources, track hardware component inventory (Arduino kits, sensors, Raspberry Pis), and book mentorship slots.

### 14. 🏆 Hackathon Leaderboard & Live Submission Portal
**Description:**  
For annual SPARK hackathons, build a real-time live submission portal with countdown timers, team registration, track guidelines, and live scorecards evaluated by mentors.

### 15. 🤖 SPARK AI Assistant Chatbot Widget
**Description:**  
Integrate a lightweight floating AI assistant widget trained on SPARK's documentation, past workshops, and society guidelines to answer student queries regarding how to join and upcoming initiatives.

### 16. 📱 Progressive Web App (PWA) & Offline Access
**Description:**  
Configure `next-pwa` with service workers and web app manifests so students can install the SPARK MSIT web app directly onto their Android/iOS devices for fast offline access to workshop schedules.

## 🛠️ Getting Started on an Upgrade
1. Choose an upgrade from the list above based on your interests and skill level.
2. Review the branch workflow in [CONTRIBUTING.md](./CONTRIBUTING.md) — **always create a feature branch, never work directly on `main`**.
3. Discuss your proposed technical design with the **Tech Head** or **Deputy Tech Head (Ritik Jha)**.
4. Build, test thoroughly with `npm run build`, and submit your Pull Request!
